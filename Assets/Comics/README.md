## 归档约定

新增漫画时先按归档提交顺序建立编号题目目录，目录与题目格式为 `【NN_题目】`，再把各语言版本按语言代码放入同一目录；连续多话作品按 `话次_题目.png` 存放，并保留分镜、台词、角色出镜列表和作者/日期。体积较大的 PSD/Procreate 源文件可使用 Git LFS。
