# 四格漫画

当前包含夏珩与夏依恩共同出镜的四格漫画：

- [`Scheng_Scheien_4koma_zh.png`](Scheng_Scheien_4koma_zh.png)：中文版，1254 × 1254。
- [`Scheng_Scheien_4koma_ja.png`](Scheng_Scheien_4koma_ja.png)：日文版，2048 × 2048。

两版内容对应，画面顺序与分镜一致，仅台词语言不同。原始素材文件夹为 `Comics`。

新增漫画时建议按故事线建子目录，并保留分镜、台词、角色出镜列表和作者/日期。体积较大的 PSD/Procreate 源文件可使用 Git LFS。
